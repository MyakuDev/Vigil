Vigil Presets
=============

built-in configs. load them from the Configs tab -> Presets dropdown.

available presets:
  legit     - lowkey movement + heal
  rage      - everything on, max values
  movement  - movement features only
  stealth   - minimal, anti-detection focused
  troll     - carry + chaos

how to use:
  1. Configs tab -> Presets dropdown -> pick one
  2. it applies instantly (overwrites current feature states)
  3. save current state with Save Config if you want to keep it

how to add your own:
  - drop a .json file in this folder matching the format
