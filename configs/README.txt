Vigil Configs
=============

this folder holds every configuration file.

files:
  settings.json   - main settings (theme, menu key, toggles)
  default.json    - baseline snapshot (features + keybinds)
  *.json          - any config you save via the Configs tab

usage:
  - Configs tab -> type a name in Save Config -> saved as <name>.json
  - Auto Load Config textbox -> set a name -> loads on next execution
  - Delete Config -> removes the file

notes:
  - configs are plain JSON and editable outside the game
  - config save captures feature states + keybind assignments
  - "default" is a safe fallback
